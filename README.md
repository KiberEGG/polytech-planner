# Планирование мастер-классов для школ

Система распределяет школьные группы по мастер-классам, аудиториям и времени
Политеха. Школы подают заявки через веб-форму, администратор принимает их,
запускает автоматическое распределение и при необходимости правит расписание
вручную в сетке на день.

Стек: Python 3.12+, Django 5.2, PostgreSQL 16, openpyxl.

## Запуск

```bash
pip install -r requirements.txt
docker compose up -d db              # или свой PostgreSQL, см. переменные ниже
python manage.py migrate             # создаст таблицы и корпуса Политеха
python manage.py createsuperuser
python manage.py seed_demo           # необязательно: демо-аудитории, окна, заявки
python manage.py runserver
```

Подключение к БД задаётся переменными `POSTGRES_DB`, `POSTGRES_USER`,
`POSTGRES_PASSWORD`, `POSTGRES_HOST`, `POSTGRES_PORT` (по умолчанию
`planner/planner/planner@localhost:5432`). Для боевого запуска задайте также
`DJANGO_SECRET_KEY`, `DJANGO_DEBUG=0` и `DJANGO_ALLOWED_HOSTS`.

## Где что

| Адрес | Для кого | Что там |
|---|---|---|
| `/` | школы | форма заявки (раздел 4 концепции) |
| `/admin/` | администратор | справочники, заявки: принять / отклонить / распределить |
| `/staff/` | администратор | сетка на день: перетаскивание занятий, окна аудиторий, преподаватели |
| `/staff/report/day/`, `/school/`, `/teacher/` | администратор | расписание в трёх разрезах и выгрузка в Excel |

## Как устроено

- `planner/models.py` — 13 таблиц из раздела 9 (`lesson` — центральная).
- `planner/rules.py` — жёсткие и мягкие правила (раздел 5). Одни и те же
  проверки используются распределением и ручной правкой.
- `planner/scheduler.py` — автоматическое распределение (раздел 6).
- `planner/services.py` — принятие заявки (школа и классы попадают в
  справочник), ручная постановка занятия, снятие занятий при сдвиге окна.
- `planner/signals.py` — при изменении или удалении окна аудитории занятия,
  которые перестали помещаться, получают статус «конфликт».

Отступления от концепции:

- у занятия есть поле `allow_repeat` — отмена проверки повтора для отдельного
  занятия (раздел 5 это допускает, но в таблице раздела 9 поля нет);
- преподаватель проверяется только на пересечение по времени, без 10-минутного
  перерыва — в правиле он не указан.
